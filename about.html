How we tested, and who we are

Appliance Energy Australia is a student project that turns public appliance data into clear, honest visualisations. This page is the method and the fine print behind every number on the site.

Why this site exists

Energy labels contain useful information, but the numbers are easy to overlook in a shop. This site aims to show that information in a way people can explore, so they can compare appliances and understand what their choices mean for their power bill.

Who it is for

The Televisions page is written for Australian households choosing a new TV. They want to know whether a bigger or more premium screen will noticeably increase their power bill, and how to compare models in the shop.

How we tested

Source

The site uses appliance registration data published by the Australian Government through the Energy Rating program. The television data set is the extract dated 15 February 2026. Each row is one registered model, with its screen size, screen technology, star rating and labelled energy consumption.

Processing

The data was cleaned and summarised in KNIME. Only models marked as available and sold in Australia were kept, and brand names that appeared in more than one form were merged. Screen size was converted from centimetres to inches and grouped into small (43 inches or less), medium (44 to 65) and large (66 or more). Average energy use and an example yearly cost were then calculated for each group and screen type, and exported as CSV files for the charts.

Privacy

The data set describes products, not people. It contains no personal information, only brand and model details submitted by the companies that register their televisions.

Accuracy and limitations

Energy figures come from a standard test that assumes 10 hours of viewing a day, so real use will differ. Standby power is not included in the running costs. A few screen sizes look like they may have been entered incorrectly. The data counts models, not sales, so a brand with many models is not necessarily the most popular. The $0.33/kWh price is an example, and real tariffs vary by state and retailer.

Ethics

The site does not recommend any brand or model. Charts start at zero and use the same scale within each chart so differences are not exaggerated. Averages are shown with the number of models behind them where the group is small.

How it is built

The pages use HTML, a single external CSS file and plain JavaScript. Charts are drawn with the D3.js library. The code is kept in a public GitHub repository, and the site is built to be hosted on Swinburne's Mercury web server.
